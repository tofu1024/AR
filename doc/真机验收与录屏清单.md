# 真机验收与录屏清单

各项按实际结果标记。1.2.1 的稳定放置和 1.3 的无绿色框放置已有用户确认，全面回归仍待执行。

## 真机验收

- [x] 支持 ARCore 的 Android 手机能够安装并启动 App（1.3 已核实）。
- [ ] 首次相机授权正常，拒绝后重新授权可以恢复。
- [ ] 扫描地面或桌面，出现水平面边界线框。
- [ ] 使用 1.2.1 扫描有纹理的墙面，出现竖直平面边界，选择内部落点并稳定后按 Place marker 放置。
- [ ] 墙面标记贴在表面朝相机一侧，没有沿世界竖直方向错误偏移；上报坐标仍为命中点。
- [x] 1.2.1 光标变绿后按 Place marker 成功放置（用户确认）。
- [ ] 移动手机观察锚定标记，量化漂移并验证跟踪恢复。
- [ ] 再次选点并确认可替换锚定标记；创建失败时保留旧标记。
- [ ] 切换平面、瞄准大幅移动或跟踪丢失时，绿色状态和确认按钮立即失效。
- [ ] 点击地址、标题、描述、优先级和提交按钮，不误放置或移动标记。
- [ ] 未放置或标题为空时无法提交，并显示原因。
- [ ] 输入标题、描述和 low/medium/high 均可上报。
- [ ] 中文输入及软键盘行为可接受。
- [ ] 提交期间不能重复点击提交，也不能改变待提交标记。
- [ ] 手机提交成功后，电脑 React 刷新看到相同标题、优先级和坐标。
- [ ] React 修改为 in_progress、resolved、open 后刷新仍正确。
- [ ] 停止 Go，手机提交显示失败且保留输入与标记；恢复后可重试。
- [ ] 停止 Go，React 显示错误；恢复并刷新后可继续使用。
- [x] 使用同一 DB_PATH 重启 Go，问题和最新状态仍然存在（实际运行服务前后 3 条完整记录逐项一致；待录屏展示）。

## 深度补充验收（1.3）

- [x] 当前手机日志显示 Depth ready 和独立 Depth 候选来源。
- [x] 无绿色平面边框时也能成功放置（用户确认）。
- [ ] 深度过期、切后台或不支持时明确回退，原平面路径仍可用。
- [ ] 平面与深度明显冲突时不确认，恢复一致后可重新稳定。
- [ ] 纯深度 Anchor 的替换、移除、跟踪恢复与上报坐标核对。
- [ ] 同场景比较误放、拒绝放置、位置误差及帧率。

## 手机视频（3～5 分钟）

1. 展示设备运行 App 和相机画面。
2. 扫描水平面，出现线框。
3. 展示黄色预览变绿，按 Place marker 放置，再移动手机展示空间位置。
4. 点击表单并填写问题，展示 UI 操作不会移动标记。
5. 选择优先级并提交，展示成功提示。
6. 时间允许时，展示空标题或网络失败提示。

## 电脑视频（3～5 分钟）

1. 展示 Go 启动日志，确认使用的数据库路径。
2. React 刷新，找到手机视频中上报的同一问题。
3. 修改处理状态并刷新确认。
4. 停止 Go，展示 React 错误提示。
5. 使用同一启动方式和数据库路径重新启动 Go。
6. React 刷新，确认问题及状态仍然存在。
